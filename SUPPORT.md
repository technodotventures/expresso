# Support

Expresso is an open-source language, verifier, runtime core, CLI, and Codex
authoring plugin for consequential agent actions.

- Use [GitHub Issues](https://github.com/technodotventures/expresso/issues) for
  reproducible compiler, CLI, plugin, and synthetic-runtime defects.
- Use a semantic proposal issue before changing language, authority, identity,
  recovery, or provider-contract behavior.
- Include the Expresso version, Node.js version, command, minimal synthetic
  source, and complete diagnostics.
- Do not include credentials, production identifiers, customer data, or
  provider secrets.

For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md) and report
privately. General support covers the released Expresso components; it does not
include operating a user's deployment host, incident response for external
providers, or guarantees that a third-party API behaves exactly once.
